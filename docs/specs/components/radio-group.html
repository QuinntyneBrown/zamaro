Sizes

One size per variant: a 20 px dot in a 44 px choice row, a 24 px dot in a radio row, cards sized by their grid column.

States

Hover and focus are forced with data-state (on the label for radio rows and cards, on the input for choice and stub rows); the rest use real attributes. Forced focus on a radio row sets outline: none on the label so only the dot shows the ring, as in the product.
