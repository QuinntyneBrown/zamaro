Sizes

The wrapper has one size. The control inside sets the height (see text field and select); the layout sets the width.

States

The field has no states of its own; it shows the parts that match its control. Focus is forced with data-state; busy is a real form[aria-busy="true"] ancestor with the control read-only (or disabled, for a select).

Responsive

Real viewports: each frame is an iframe of that width. The longest label and its two help lines wrap at 320 px; the counter keeps the end of the row while “Note to Tobi (optional)” wraps beside it; the inline sort keeps 12 rem in a heading row; full-width fields span the grid at 768 px.

Not renderable on a static page, and checked by the acceptance tests instead: AC-9, AC-11 (live announcements), AC-17, AC-18 (keyboard and focus), AC-19 (computed description), AC-21 (axe-core), AC-26 (200 % zoom), AC-27 (French catalogue), AC-28 (reduced motion), AC-29 (perf test)
