Placements

Specimens use the design system’s static .tooltip-anchor markup with data-state="open". In the product the label opens in a CDK overlay with the same classes, outside the anchor (D-1), and is aria-hidden because the description lives in a hidden AriaDescriber element (D-7).

Responsive

The tooltip does not change across breakpoints; what matters at phone widths is the viewport edge. In the product the CDK overlay shifts the alignment itself; here the frames show the alignment it chooses.
