Responsive

Real viewports. Below 992 px the settings nav is one row that scrolls inside itself; the panel is hidden there (its links live in the top bar’s drawer).

The 360 px dark frame’s row holds “Your data” current: the component scrolls the row (not the page) to reveal it. Not renderable here: scroll tracking and focus after activation (AC-5, AC-6, AC-7), landmark listing (AC-19), reduced motion (AC-25), French copy (AC-24) and the perf scenarios (AC-26).
