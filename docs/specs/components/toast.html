Responsive

Real viewports: each frame is an iframe with the fixed region, so the 576 px breakpoint and the bottom offsets apply.

The last frame sets --zm-toast-offset to a sticky booking bar’s height, so the toast sits above the bar. AC-32

Reduced motion and the perf scenarios are not renderable here. AC-36, AC-37
