Responsive

Real viewports: each frame is an iframe at that width, so the footer's 768 px and 992 px grid changes and the word's container sizing apply.

Under a coarse pointer the links grow to 44 px targets; that, 200 % zoom and the perf budget are measured, not rendered. AC-21, AC-22, AC-24
