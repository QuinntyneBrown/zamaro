Sizes

One size: at least --layout-topbar-height (68 px including the rule) at every width. Only the contents change with the breakpoint (see Responsive).

Responsive

Real viewports: each frame is an iframe at that width, so the bar’s own breakpoints (400, 480, 576, 992, 1200 and 1536 px) apply. The bars are not sticky inside the frames.

At 200 % zoom the CSS viewport halves, so a 1280 px window shows the 640 px (compact) layout above. AC-25
