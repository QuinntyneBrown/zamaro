Responsive

Real viewports: each frame is an iframe at that width, so the dialog’s own breakpoint at 576 px applies. Below it the dialog fills the screen, the header stays at the top, only the body scrolls and the footer is pinned. Its buttons fill the width: side by side when both labels fit (“Not now” / “Pay $162.50”), otherwise one per row with the way back first (the 320 px and dark 360 px frames, D-15). The short-viewport rule (D-16) is not in the design-system stylesheet yet, so it is not rendered here.
