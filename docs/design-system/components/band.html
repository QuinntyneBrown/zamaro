Band

The band is the yellow strip near the end of a page that asks a different audience to act. On Discover it asks worship leaders to join: “Lead worship? Get on the bill.”

Overview

Use the band once per page, after the main content and before the footer, for a secondary audience or a secondary goal. On Discover the page is for bookers; the band speaks to artists.

  • One action, with an optional text link for “learn more”.
  • Not for the page’s main action: that is the yellow primary button (“Show the lineup”). A yellow band and a yellow button compete only if they ask the same reader to do the same thing.
  • Not for system news or warnings: use a banner.
  • Not for decoration: the marquee is the decorative yellow strip.

Anatomy

  1. OverlineWho it is for: “For artists”. Mono, 12px.
  2. HeadlineAn <h2> set in --text-h1: a question and an answer.
  3. BodyOne or two short sentences with the terms.
  4. ActionA large button re-skinned as a charcoal stage button (.band .btn). Right of the copy from 992px.
  5. BandYellow fill, ink text, 4px ink frame, 40/32px padding (48px from 992px).

Apply as an artist
  • Hover lifts the stage button over a hard paper shadow, so it looks printed on top of the yellow.
  • Focus draws an ink ring (--color-border-on-accent) on yellow; the stage yellow ring would vanish.
  • Busy applies only if the band submits a form in place (for example “Notify me”). Navigating links have no busy state.
  • The text link’s hover (paper highlight) has no data-state hook; this specimen draws it with token styles.

Responsive behaviour

  • Under 992px the copy and the button stack, button below, left-aligned. Padding is 40px top and bottom, 32px at the sides.
  • From --layout-breakpoint-lg (992px), the copy takes the remaining width and the button sits right, vertically centred, 40px away. Padding becomes 48px.
  • The headline is --text-h1 (48–88px) and wraps in balanced lines. Keep it under eight words.
  • On a 360px phone the band leaves about 256px for the button. “Apply as an artist” with its arrow just fits on one line; a longer label wraps onto balanced lines, so keep it to three or four words.

Theming

The band reads --color-accent for the fill, --color-fg-on-accent for text and --color-border-on-accent for the frame. These are the same in both themes, so the band is identical in light and dark; only its surroundings change.

It re-skins buttons inside it through their component tokens:

.band .btn { --btn-bg: var(--color-bg-stage); --btn-fg: var(--color-fg-on-stage); --btn-border: var(--color-bg-stage);
             --btn-shadow-hover: var(--size-offset-2) var(--size-offset-2) 0 var(--color-fg-on-stage); }
.band :focus-visible { outline-color: var(--color-border-on-accent); }

Accessibility

Role and pattern

A plain <div class="band"> inside a <section> labelled by the band’s <h2>, so it appears in the landmarks list as “Lead worship? Get on the bill.” The action goes somewhere, so it is a link styled as a button (<a class="btn">), not a <button>.

Keyboard

KeyAction
Tab / Shift+TabMoves to the text link (if any), then the button, in reading order.
EnterFollows the link.

Focus

Inside the band the 3px ring is ink, 8:1 against the yellow. The stage button’s ring sits 3px outside it on the yellow, not on the button.

Labelling

The visible text is the accessible name: “Apply as an artist”. The arrow icon is aria-hidden. If the band has two links, their text must differ (“See what artists earn” and “Apply as an artist”).

Contrast

Motion

Only the button lifts, in --duration-fast; instant under prefers-reduced-motion. The band itself never animates in.

Touch

The large button is 56px tall. A text link in the body copy is at least 24px tall through line height and is never the only way to act.

Content

  • Overline: the audience, “For artists” or “For churches”.
  • Headline: a question the reader would answer yes to, then the offer, in poster voice: “Lead worship? Get on the bill.”
  • Body: the terms in plain numbers: “Free to join; Zamaro keeps 8% when a church books you.”
  • Button: verb first, three or four words: “Apply as an artist”. A trailing arrow means it goes to another page.

Drift fixed during extraction:

  • The band button set background, color and border-color from --palette-ink and --palette-paper, and its hover shadow from --palette-paper-bright. It now overrides the button’s component tokens with stage tokens.
  • Band links and the focus ring read --palette-ink. They now read --color-fg-on-accent (inherited) and --color-border-on-accent.
  • The band read --palette-ink for its frame. It now reads --color-border-on-accent.
  • “Apply as an artist” was a <button type="button"> that navigated. The mocks now use a link to the apply page, as this page documents.
