Headliner

The headliner is the top of the bill: the best match for the booker’s date, shown larger than the rest of the lineup, with a church’s own words about why.

Overview

Use one headliner at the top of a lineup, above the tickets. It is “No. 01”: the artist Zamaro would book first for that date and place, usually the most-booked artist who is free. It answers two questions before the booker scrolls: is someone good free, and what do churches say about them.

  • Only one per page. If no artist is free, there is no headliner; show the empty state instead.
  • Not for ads or sponsored artists. The headliner is earned by availability, distance and reviews.
  • Not on the profile page: the profile already has the artist poster.

Anatomy

  1. Art.art.art--yellow: the only yellow halftone in the lineup, 4:5 portrait. role="img" with a description.
  2. Tag.art__tag “Headliner”: ink label on the art, mono overline.
  3. Number and reason.overline: “No. 01 · Most booked this autumn”.
  4. Name.headliner__name: --text-display (64–160px), the link to the profile. Hover fills it yellow.
  5. Meta.headliner__meta: four stub-font facts: style, town and distance, rating, price.
  6. QuoteOne review sentence in curly quotes, with the reviewer muted after a dash.
  7. ActionsFree badge, ink button to the profile, save toggle.
  8. FramePaper surface, 4px --border-width-poster frame, hard 8px --shadow-3, 32–40px padding.

Variants

The headliner has one layout. It varies by what is known about the artist: a halftone placeholder or a real photo, and whether the booker has saved them.

While the lineup loads, the headliner frame holds skeletons sized like the real parts, so nothing jumps. It is a <div> with aria-hidden, not an article.

Sizes

The headliner has one size: it spans the lineup column, and its type scales with the viewport through clamp() tokens.

  • Name hover fills the name yellow with ink type, like a highlighter on the poster. Focus shows the 3px ring.
  • Saved fills the round toggle yellow with a filled heart. Saving pulses the heart while the request is in flight.
  • Loading: the skeleton frame shown above. Empty and error: there is no headliner; the empty state or alert takes the lineup’s place.

Responsive behaviour

  • Under 768px: art on top (full width, 4:5), copy below, 32px padding.
  • From --layout-breakpoint-md (768px): two columns, art at 16rem and copy bottom-aligned beside it.
  • From --layout-breakpoint-lg (1024px): art at 20rem, 40px padding and gap.
  • The name breaks anywhere (overflow-wrap: anywhere) rather than scroll sideways. Meta facts and actions wrap as units.

Theming

The frame reads --color-bg-surface, --color-border-strong and --shadow-3, so in the dark theme it becomes a charcoal panel with a light frame and a yellow print shadow. The yellow art reads --color-accent with --color-border-on-accent dots, and the tag the inverse pair, so they look the same in both themes. The ink button uses the inverse pair too, which makes it paper-coloured in the dark theme.

No component tokens. The name hover reads --color-accent and --color-fg-on-accent.

Accessibility

Role and pattern

An <article> labelled by the name’s heading (aria-labelledby). The name is an <h3> under the lineup’s <h2>, at the same level as the ticket names that follow. It contains two links to the same profile (name and button): that is deliberate, because the button gives a large target and a clear label, and both have distinct text. The save toggle follows the APG Button pattern with aria-pressed.

Keyboard

Focus

Each control shows the 3px ink ring (yellow in the dark theme). The name’s ring hugs the text, so a two-line name shows a ring per line.

Labelling

The art is role="img" with a description of the photo; the “Headliner” tag inside it is part of that image and is not read separately. With a real photo, the <img alt> carries the description and the wrapper has no role. The quote’s reviewer is plain text after a dash. The save toggle names the artist.

Motion

The ink button lifts on hover (--duration-fast) and the save toggle snaps (--ease-spring); both drop to instant under prefers-reduced-motion. The frame never moves.

Touch

The button and toggle are 44px, 8px apart. The name is a large target on its own at display size.

Content

  • Number line: “No. 01 · ” and why this artist leads: “Most booked this autumn”, “Closest band with five stars”. Never “Featured” or “Sponsored”.
  • Meta: style, town · distance, rating (churches), “From” price. Four facts, no more.
  • Quote: one sentence from a real review, in curly quotes, naming something specific that happened. Attribute with name and town.
  • Button: “See {first name}’s profile”. For groups use the full name: “See Hosanna Collective’s profile”.
  • Badge: “Free Sat 14 Nov”, the date the booker searched.
