Select

A select picks one value from a list Naomi doesn’t need to see all at once: the kind of gathering, how far an artist will drive, how to sort the lineup. It is the browser’s own control, dressed in a charcoal rule.

WCAG 2.2 AAStatus: stableNative <select>Class .select

Overview

Use a select for one choice from five to fifteen known options when the options do not need explaining. Zamaro always uses the native <select>: it gets the phone’s own picker, type-ahead, screen-reader support and autofill for free.

  • Two to four options that each need a sentence: use a radio group or choice cards, so all options are visible.
  • Several values at once: use checkboxes or filter chips.
  • An action list (“Share”, “Remove from saved”): use a menu, never a select.
  • Hundreds of options or free text with suggestions: a combobox (not in the system yet).

Changing a select never submits or navigates by itself (WCAG 3.2.2). The lineup’s sort is the one exception that re-orders results in place, and it announces the new order.

Anatomy

  1. LabelFrom the form field.
  2. BoxSame as a text field: 44px, square, 2px charcoal rule, surface fill. 40px right padding leaves room for the chevron.
  3. Selected valueBody text, 16px. Never truncated with an ellipsis in a way that hides the meaning; keep options short.
  4. ChevronDrawn in CSS from currentColor, so it greys out with the text when disabled. No icon file.

Variants

Kind of gathering and radius

From the booking bar. The radius options pair the distance with a drive time, separated by a middle dot, because coordinators think in minutes.
HTML
<div class="field">
  <label class="field__label" for="se-kind">Kind of gathering</label>
  <select class="select" id="se-kind" name="kind">
    <option selected>Sunday service</option><option>Worship night</option><option>Youth event</option>
    <option>Conference or retreat</option><option>Wedding</option><option>Funeral or memorial</option>
  </select>
</div>
<div class="field">
  <label class="field__label" for="se-radius">How far can they drive?</label>
  <select class="select" id="se-radius" name="radius">
    <option value="40">40 km · 30 min</option><option value="80">80 km · 1 hr</option>
    <option value="120" selected>120 km · 1.5 hr</option><option value="200">200 km · 2.5 hr</option>
  </select>
</div>

With a placeholder option

Only when there is no sensible default. The placeholder is disabled so it cannot be chosen back, and required catches an empty submit.
HTML
<div class="field">
  <label class="field__label" for="se-kind-empty">Kind of gathering</label>
  <select class="select" id="se-kind-empty" name="kind" required>
    <option value="" selected disabled>Choose one</option>
    <option>Sunday service</option><option>Worship night</option><option>Youth event</option>
  </select>
</div>

Inline sort

In the lineup heading row, with .field--inline for a 12rem minimum. On compact toolbars the same choice can be a sort menu.
HTML
<div class="field field--inline">
  <label class="field__label" for="se-sort">Sort</label>
  <select class="select" id="se-sort" name="sort">
    <option selected>Closest first</option><option>Highest rated</option><option>Price, low to high</option>
  </select>
</div>

Sizes

Match the size of the fields and buttons beside it. Medium is the default.

.select--sm and .select--lg use --control-height-sm/lg. Small uses 14px text, so keep it off phone layouts.
HTML
<select class="select select--sm" aria-label="Small example"><option>Small · 36px</option></select>
<select class="select" aria-label="Medium example"><option>Medium · 44px</option></select>
<select class="select select--lg" aria-label="Large example"><option>Large · 56px</option></select>

States

Hover and focus are forced with data-state. “Open” is drawn by the operating system and cannot be styled.

VariantDefaultHoverFocusInvalidDisabled
Value
Placeholder

Selects have no read-only state in HTML. Show a read-only value as text or as a read-only text field.

Both themes

  • Invalid happens only for a required select left on its placeholder. Pair it with “Choose a kind of gathering.”
  • Disabled while a dependent value is missing is a trap: Naomi can’t tell why. Prefer showing all options and explaining a bad combination in the error.
  • Open uses the platform list: a sheet on iOS, a dropdown on Android and desktop. Its colours follow the browser’s color-scheme.

Responsive behaviour

  • Full width of its field. The inline sort keeps a 12rem minimum and sits under the heading on phones.
  • On phones the open list is the system picker, which is easier to use with a thumb than any custom dropdown.
  • The longest option decides nothing about the width; the field does. Keep options under about 24 characters so the value does not clip at 360px.

Theming

The select shares the field component tokens with text fields: --field-bg, --field-fg, --field-border and --field-height. It adds appearance: none and draws the chevron with two gradients in currentColor, so the chevron follows the text colour in every theme and state.

The open list is styled by the browser. Setting color-scheme per theme (the token sheet does) makes it dark on the dark theme.

Accessibility

Role and pattern

Native <select> (a combobox with a listbox popup in the accessibility tree). Use it before any custom widget; a custom listbox would have to follow the APG Listbox pattern and still lose the phone picker.

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the select.
↑ / ↓Changes the value (Windows) or opens the list (macOS).
Alt+↓ / SpaceOpens the list.
A letterJumps to the next option starting with it (“W” → Worship night, Wedding).
Enter / EscChooses / closes without changing.

Focus

The double ring (--shadow-focus) around the box, the same as text fields.

Labelling

A visible <label>. Option text is what gets announced, so write options that stand alone (“120 km · 1.5 hr”, not “1.5”). The placeholder option is not a label. Errors link through aria-describedby.

Contrast

Motion

Only the rule colour and ring fade (--duration-fast). The open list animates as the platform does.

Touch

44px tall, full width; the system picker handles the rest.

Content

  • Options in sentence case, short and parallel: “Sunday service”, “Worship night”, “Youth event”.
  • Order options by how often they are picked, or by size for ranges (40, 80, 120, 200 km).
  • Add the detail a coordinator needs after a middle dot: “120 km · 1.5 hr”.
  • Default to the most likely option (Sunday service, 120 km). Use “Choose one” only when guessing would be wrong.
  • Sort options describe the order: “Closest first”, “Price, low to high”.
