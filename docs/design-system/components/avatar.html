Avatar

An avatar is a round yellow token with someone’s initials, photo or an icon. In the top bar it is Naomi’s “NF” button that opens her account menu.

Overview

Use an avatar to help people recognise a person or an act next to its name: the signed-in booker, the artist on a request, the church that wrote a review. It is never the only place a name appears.

  • As a button (<button class="avatar">) it opens the account menu. It is the only interactive avatar.
  • As a picture (<span class="avatar">) it sits beside a name in a list, a review or a request, and is hidden from assistive technology.
  • For artist portraits on profiles and tickets, use artwork, not a large avatar.

Anatomy

  1. DiscA full circle, yellow --color-accent. Size from --avatar-size: 32, 40 or 56px.
  2. ContentTwo initials in the mono stub face, bold and uppercase; or an image that covers the disc; or a 55% icon.
  3. Outline2px --color-border-on-accent, the ink edge that keeps yellow from melting into paper.
  4. Status dot (optional)Shown enlarged with the disc here. 12px --color-success-solid with a 2px paper ring, bottom right of .avatar-wrap.

Variants

Initials are the default. Use an image only when the person uploaded one, the ink variant to tell an act apart from a person, and an icon when there is no name yet.

Sizes

Medium (40px) is the default: the top bar and list rows. Small (32px) fits dense rows and groups. Large (56px) is for a review byline or the account menu header.

NF NF NF
.avatar--sm 32px · 12px initials; default 40px · 14px; .avatar--lg 56px · 16px. Sizes come from --avatar-size.

Only the button avatar has states. Hover and focus are forced with data-state.

  • Focus draws the shared ring: ink on paper, yellow on the stage.
  • Menu open keeps the ring while the menu has focus nearby and exposes aria-expanded="true"; the disc itself does not change.
  • Loading: before the person is known, show a .skeleton--circle of the same size, never a placeholder “?”.
  • Image failed: fall back to initials on the same disc. Don’t show a broken-image icon.

Responsive behaviour

  • Avatars never scale with the viewport; they keep their size and never shrink in a flex row (flex: none).
  • In the top bar the “NF” button stays at every width; on phones it sits beside the menu button and the Saved heart.
  • Groups show at most three avatars plus a count at every width. On a phone, drop to two plus the count if the row is tight, and update the count and the group’s name to match.

Theming

The avatar has one component token, --avatar-size, which the size modifiers set. Colours are semantic: the disc is --color-accent, initials are --color-fg-on-accent and the outline is --color-border-on-accent; the ink variant uses --color-bg-inverse and --color-fg-inverse. Groups ring each disc in --color-bg-surface so overlaps read as separate tokens; the status dot does the same.

In the dark theme the yellow disc and its ink initials stay the same, which makes Naomi’s “NF” the brightest thing in the top bar on both themes. The ink variant flips to a paper disc with charcoal initials.

Accessibility

Role and pattern

The account avatar is a native <button> that opens a menu, following the APG Menu Button pattern with aria-expanded and aria-controls. Every other avatar is a picture: aria-hidden="true" when the name is next to it, or role="img" with a name when it stands alone.

Keyboard

KeyAction
TabReaches the account avatar button. Picture avatars are skipped.
Enter / SpaceOpens the account menu and moves focus to its first item.
EscCloses the menu and returns focus to the avatar.

Focus

The shared ring, 3px with a 3px offset, follows the circle’s bounding box. On the stage (top bar) it turns yellow; the offset gap keeps it apart from the yellow disc.

Labelling

The button’s name says what it does and whose it is: “Account menu for Naomi Fraser”. The initials are not a name. Image avatars beside a name use alt=""; standalone ones use the person’s name as alt. Groups are one role="img" whose name lists who is shown and how many more. The status dot has role="img" and a name (“Online now”), and the same status appears in text.

Motion

The hover grow uses --duration-fast and --ease-spring. Under prefers-reduced-motion the duration drops to near zero, so the disc simply appears larger.

Touch

The account button is 40px; with the top bar’s padding its effective target is 44px or more. Small 32px avatars are never buttons. Nothing depends on hover.

Content

  • Two initials: first and last name for a person (“NF”), the first two words for an act (“HC” for Hosanna Collective, “MB” for Marcus Bell Trio). For “Daniel & Ruth Okonkwo” use “DR”.
  • Overflow counts are “+4”, never “4+” or “and 4 more” inside the disc.
  • Image avatars are the person’s own photo, cropped to the face. Never stock photos.
  • The button’s label is “Account menu for {full name}”.
