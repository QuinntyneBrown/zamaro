Top bar

The masthead on every page: the Zamaro brand, where you can go, how many artists you have saved and who is signed in. It sits on the charcoal stage with a yellow rule under it.

Overview

Every Zamaro page starts with the same top bar, in the same order, so a booker always knows where Discover, Saved and their account are. It is the page’s <header> landmark and sticks to the top of the viewport while the page scrolls.

  • Brand links home (Discover). The yellow .brand-mark holds the microphone icon.
  • Primary navigation (.topbar__nav) holds three to five .nav-links. The current one has aria-current="page" and a yellow underline.
  • Saved is a .nav-link with a yellow count badge. In the mocks it links to the Saved artists page.
  • Theme toggle (.topbar__theme) switches between the newsprint and stage themes (L2-104). From 992px it is an icon button in the bar; in the compact header it is a “Dark theme” item in the navigation drawer.
  • Account is an initials avatar button that opens the account menu. Signed out, a “Sign in” link (or “Create account” on the sign-in page) takes its place.

The two workspaces use the same bar with .topbar--workspace: a role tag after the brand, five workspace links, and no Saved button. The artist area’s tag reads “Artists”; the separate admin app under /admin uses the same bar with an “Admin” tag and its own five links.

Use it once per page, as the first thing after the skip link. Do not put page actions (“Request to book”, filters) in it: those belong in the page. For sections inside an account area, use sidebar navigation or tabs under the top bar.

Anatomy

  1. Brand.topbar__brand: a 32px yellow .brand-mark with the microphone icon (aria-hidden) and the word “Zamaro” in the display face. The word is the link’s name.
  2. Primary navigation.topbar__nav inside <nav aria-label="Primary">. Bold 14px uppercase labels, 44px tall, 12px side padding.
  3. Current markerA 3px yellow underline drawn with an inset shadow on the link with aria-current="page".
  4. Saved button.nav-link.topbar__saved: heart icon, “Saved” label and a yellow .badge--count. Links to the Saved artists page.
  5. Account buttonbutton.avatar with the booker’s initials, 40px, yellow fill with an ink ring. Opens the account menu.
  6. Stage and ruleCharcoal --color-bg-stage in both themes, 68px tall, with a 4px --color-accent rule along the bottom.

Variants

There is one top bar. What changes is who is signed in and how wide the screen is. The examples use .topbar--static so they do not stick to the top of this page.

Theme toggle

One toggle for the whole product (L2-104). It is a toggle button with a constant name, “Dark theme”, and aria-pressed="true" while the stage theme is on; the name never flips to “Switch to light theme”, because a changing name and a pressed state would contradict each other. In the bar it is a ghost icon button: the moon icon fills and turns yellow when pressed. In the compact header it moves into the navigation drawer as a .menu__item button with the same name and state (see Menu).

Off (newsprint) and on (stage). Shown from 992px; below that it lives in the drawer.
HTML
<button class="btn btn--ghost btn--icon topbar__theme" type="button" aria-pressed="false">

  <span class="visually-hidden">Dark theme</span>
</button>

Both themes

Zamaro
Zamaro
  • Hover turns a link or the Saved button yellow (--color-accent-on-stage). Nothing lifts: the stage is already the loudest surface on the page.
  • Current adds a 3px yellow underline. The link stays a link, so a booker can reload Discover from Discover.
  • Open (aria-expanded="true") keeps the Saved label yellow while its panel is showing. When a save changes the count, the badge updates in place (3 → 4) and a toast confirms it.
  • Focus is a yellow ring on the stage in both themes.

Responsive behaviour

  • 992px and wider (LG, --layout-breakpoint-lg): brand, primary links, a flexible spacer, Saved with its label, the theme toggle, then the avatar. Side padding is --layout-margin, so the bar lines up with the page container.
  • Below 992px (XS, SM, MD): .topbar__nav and .topbar__theme are hidden and the ghost menu button (.topbar__menu) appears before the brand. It opens the navigation drawer with the same links in the same order plus the “Dark theme” toggle. Saved and the avatar stay visible; Saved shows only the heart and count (L2-099).
  • Workspace bar (.topbar--workspace, artist and admin): five links need more room, so it keeps the menu button and drawer until 1200px (XL) and shows the links inline from there. .topbar__link (“View public profile”) shows only from 1536px.
  • At 360px: menu (44px), brand, spacer, Saved (about 70px) and avatar (40px) share one row at the same 68px height. Below 576px the gaps tighten to --space-2 and the word “Zamaro” drops to 22px (--font-size-xl); below 400px it drops again to 18px (--font-size-lg), so the row still fits when the condensed display face falls back to a wider one. The signed-out “Create account” link shortens to “Sign up” below 480px.
  • The bar is position: sticky. html sets scroll-padding-top to --layout-topbar-height plus 16px, so in-page links (“Book for Sat 14 Nov”) and focused fields are never hidden under it.

Theming

The top bar is a stage surface in both themes, so the newsprint theme and the stage theme look almost the same here: on light the stage is --palette-ink-850, on dark it drops to --palette-ink-950 so it still sits darker than the dark canvas. It reads semantic tokens only: --color-bg-stage, --color-fg-on-stage, --color-accent-on-stage (hover, current underline, focus ring) and --color-accent (the bottom rule, brand mark and count badge).

It has no component tokens of its own. The controls inside it are re-skinned by context: .topbar .btn--ghost resets --btn-fg to currentColor and --btn-fg-hover to --color-accent-on-stage, and the count badge keeps its --badge-bg: var(--color-accent) with an ink outline from --color-border-on-accent.

/* Links inside the stage inherit paper and turn yellow on hover */
:is(.on-stage, .topbar) a:not(.btn) { color: inherit; }
:is(.on-stage, .topbar) a:not(.btn):hover { background: none; color: var(--color-accent-on-stage); }

Accessibility

Role and pattern

The bar is a <header> that is a direct child of <body>, so it is the page’s banner landmark. The links sit in <nav aria-label="Primary">. The menu button and the Saved button follow the APG Disclosure pattern (aria-expanded, aria-controls). The account avatar follows the APG Menu Button pattern (aria-haspopup="menu").

Keyboard

KeyAction
Tab / Shift+TabMoves through menu button (compact), brand, links, Saved, theme toggle (from 992px) and avatar, in that order.
EnterFollows a link; opens the drawer or account menu; toggles the theme.
SpaceOpens the drawer or account menu; toggles the theme.
↓ / ↑In the open account menu: moves between items (see Menu).
EscCloses the open drawer, panel or menu and returns focus to the button that opened it.

Focus

The skip link is the first stop, so keyboard users can jump past the bar. The ring on the stage is yellow (--color-accent-on-stage) with a 3px offset in both themes. Opening the drawer moves focus to its first link; closing it returns focus to the menu button. Because the bar is sticky, scroll-padding-top keeps focused elements below it (WCAG 2.4.11).

Labelling

The brand link’s name is “Zamaro”; the mark is aria-hidden. The nav is labelled “Primary” and must be the only nav with that name on the page. The Saved button’s name is “Saved 3 artists”: the count badge carries visually hidden text, and on phones the word “Saved” is visually hidden rather than removed. The avatar has aria-label="Account menu for Naomi Fraser". When a save changes the count, a polite role="status" toast says so; the badge itself is not a live region.

Motion

Link colour changes take --duration-fast; the avatar grows 6% on hover with --ease-spring. The drawer slides in over --duration-slow. Under prefers-reduced-motion these durations drop to near zero and the drawer simply appears. Smooth scrolling to anchors is turned off too.

Touch

Links, Saved and the menu button are 44px tall (--target-comfortable); the avatar is 40px with at least 12px around it. Nothing depends on hover: the current page is marked by an underline, not by colour alone.

Content

  • Nav labels are one to three short words, in sentence case in the source: “Discover”, “How booking works”, “For artists” (L2-099). CSS adds the uppercase.
  • Budget the width: at 992px the bar has about 860px for content, and the brand, Saved, theme toggle and avatar take about 420px of it. The booker’s three links fit; the workspace bar’s five (artist and admin) do not, which is why .topbar--workspace stays compact until 1200px.
  • Keep three to five links. Anything more belongs in the drawer, the footer or an account page.
  • The Saved count is the number of saved artists, not a notification count. It never says “9+”; show the real number.
  • Avatars show two initials from the booker’s name (“NF”). The menu inside names the person and church.

Drift fixed during extraction:

  • The Saved button combined .nav-link, .btn--ghost and an inline style="background: none; border: 0; cursor: pointer;". .nav-link now resets buttons itself.
  • .brand-mark was 1.9rem (30.4px, off the grid) and read --palette-ink. It is now 2rem and uses --color-fg-on-accent.
  • The count badge’s minimum width was 1.4em; it is now 1.5em so “3” and “12” sit in the same box. Its outline now reads --color-border-on-accent, not the ink primitive.
  • An earlier extraction shortened “How booking works” to “How it works”. L2-099 names the link “How booking works” and every mock uses it, so the label is back; it only shows from 992px, where it fits on one line.
  • The product had no theme toggle although L2-104 requires one. .topbar__theme and the drawer item were added to every mock.
  • The artist bar’s five links, “View public profile” and the avatar overflowed at 992px. The artist bar now stays compact until 1200px and the extra link shows only from 1536px.
  • The count was named with aria-label on a plain <span>, which screen readers do not reliably read. It now carries visually hidden text.
