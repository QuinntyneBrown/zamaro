Component · Navigation

Breadcrumb

A trail of links above the page title that says where you are and takes you back up. On a profile it leads back to the lineup you came from: “Discover · Sat 14 Nov / Abigail Mensah”.

Overview

Use a breadcrumb on any page that sits below another one: an artist profile below the Discover lineup, a booking below “Your bookings”. It goes above the <h1>, inside the poster on public pages and at the top of the content on account pages.

  • The first crumb carries the context the booker arrived with. On a profile it is “Discover · Sat 14 Nov”, which returns to the same search, not to an empty Discover page.
  • The last crumb is the current page. It is plain text with aria-current="page", never a link.
  • With four or more levels, the middle collapses behind a .breadcrumb__more button.

Do not use a breadcrumb on top-level pages (Discover itself), and do not use it as a progress indicator for the booking flow: that is steps.

Anatomy

  1. Ancestor linkUnderlined, inherits the surface’s text colour. Mono 14px uppercase (--text-stub), like the small print on a ticket.
  2. SeparatorA “/” drawn by CSS before every item after the first, 8px each side.
  3. Current pagePlain text, bold, with aria-current="page".
  4. Landmark<nav aria-label="Breadcrumb"> around an ordered list (<ol class="breadcrumb">). Each item is at least 24px tall.

Sizes

Breadcrumbs have one size: the 14px stub type, on rows at least 24px tall.

States

Hover and focus are forced with data-state. Current comes from aria-current="page"; the collapse button uses aria-expanded.

  • Hover on the stage turns the link yellow; on paper it lays the yellow highlighter (--color-accent-subtle) behind the text.
  • Current is bold, not underlined and not a link, so it cannot be mistaken for somewhere to go.
  • Expanded: after “…” is pressed, the hidden crumbs appear in place and the button is removed, so focus moves to the first revealed link.

Responsive behaviour

  • The list wraps (flex-wrap) rather than scrolling. A two-crumb trail like the profile’s fits on one line at 360px.
  • Below 768px, trails of four or more levels show only the first crumb, “…” and the current page. From 768px the full trail shows unless it would wrap.
  • Long crumbs (an artist name like “Grace Tabernacle Mass Choir”) may wrap inside the item; never truncate the current page’s name.

Theming

The breadcrumb has no colour of its own: links and separators inherit the surrounding text colour (color: inherit), so it reads --color-fg-on-stage inside the poster and --color-fg-default on paper. Hover reads --color-accent-on-stage on the stage and --color-accent-subtle behind the text on paper. The underline is 55% of the text colour, as on every link.

Because the stage is charcoal in both themes, a stage breadcrumb looks the same in both. A paper breadcrumb follows the theme: on the dark theme the hover highlighter becomes a dim amber and the text stays paper-light. There are no component tokens.

Accessibility

Role and pattern

APG Breadcrumb pattern: a <nav> landmark labelled “Breadcrumb”, an ordered list of links, and aria-current="page" on the last item. The collapse button is a disclosure (aria-expanded, aria-controls).

Keyboard

KeyAction
Tab / Shift+TabMoves through the ancestor links and the “…” button. The current page is not a stop.
EnterFollows a link; reveals the hidden levels from “…”.
SpaceReveals the hidden levels from “…”.

Focus

The shared ring: ink on paper, yellow on the stage. After “…” reveals the middle crumbs, focus moves to the first of them, because the button it was on is gone.

Labelling

Only one landmark per page is named “Breadcrumb”. The “…” button needs aria-label (“Show 2 more levels”), since an ellipsis has no meaning when read aloud. The “/” separators are drawn with CSS and given empty alternative text (content: "/" / ""), so screen readers do not announce “slash” between crumbs.

Motion

None. Revealed crumbs appear instantly.

Touch

Each item is at least 24px tall (--target-min) with 8px gaps either side of the separator, which meets WCAG 2.5.8. The breadcrumb is a secondary route; the browser’s back button and the top-bar links remain the main ones on phones.

Content

  • Each crumb is the title of the page it leads to, shortened if needed: “Your bookings”, not “View all of your bookings”.
  • Carry the search context in the first crumb with a middle dot: “Discover · Sat 14 Nov”. It tells the booker the link goes back to that date’s lineup.
  • The current crumb names the current page: the artist on a profile (“Abigail Mensah”), the booking number on a booking page (“ZAM-0114”).
  • Sentence case in the source; the stub style uppercases it.
