Link

A link goes somewhere. It is always underlined, stays ink after it is visited, and highlights like a marker pen when you point at it.

WCAG 2.2 AAStatus: stableNative <a href>Class .link

Overview

Use a link when activating it only navigates: to Abigail’s profile, to “How booking works”, to the Zamaro inbox. If it changes something (saves, submits, retries), it is a button, even when it sits in a sentence.

  • Inline links sit inside running text and take its size. Every <a href> gets this look from the base stylesheet; .link applies it where a parent component has reset link styles.
  • Standalone links (.link--standalone) stand on their own line under a section, in the label style with a trailing arrow: “See all 38 reviews”.
  • External links leave Zamaro, such as an artist’s YouTube channel. They show a small arrow-out icon and tell screen readers that a new tab opens.
  • On the stage (top bar, poster, footer) links take the paper text colour and turn yellow on hover, with no fill.

A link that has to look like a button (“See Abigail’s profile”, “Back to the lineup”) is an <a class="btn">; see Button variants. A link that covers a whole card is documented on Ticket card and Card.

Visited links stay ink, by design. Bookers come back to the same few profiles every week, so a third “visited” ink would mark almost every artist and tell them nothing. Saving an artist is what records interest, and the save toggle shows it.

Anatomy

  1. LabelThe accessible name. Inline links inherit the paragraph’s type; standalone links use --text-label, uppercase, 0.08em tracking.
  2. Underline1px, 0.22em below the baseline, in the text colour at 55%. It turns solid on hover. The underline is what marks a link, not the colour.
  3. Arrow (standalone)20px stroke icon, aria-hidden. It nudges 4px right on hover. External links use a smaller arrow-out icon.
  4. Hover highlightA --color-accent-subtle fill behind the text, like a highlighter pen. Shown here forced with data-state="hover".

Sizes

Links take the size of the text around them. Standalone links use the label style at one size.

States

Hover and focus are forced with data-state. Links have no disabled state: if a destination is not available, remove the link and say why in plain text.

  • Hover fills the text with the subtle yellow and makes the underline solid. In dark mode the text itself turns yellow on a deep amber fill.
  • Focus draws the shared ring (ink on paper, yellow on the stage and in dark mode) around the link’s box.
  • Active has no extra style; the page changes right away.
  • Visited stays the same as default. See the overview for why.

Responsive behaviour

  • Inline links wrap with the sentence. Long email addresses may break anywhere (overflow-wrap: anywhere on their container) so they never push the page sideways at 360px.
  • Standalone links keep their arrow on the same line as the last word. If the label is too long for 360px, shorten it (“All reviews”) rather than letting it wrap.
  • In stacked lists (the footer), links sit --space-3 apart so each one is a separate target on a phone.
  • The external icon scales with the text (0.85em), so it stays in proportion at 200% zoom.

Theming

Links read semantic tokens directly: --color-fg-link for text, --color-fg-link-hover and --color-accent-subtle for hover, --color-focus-ring for focus. The underline is currentColor mixed to 55%, so it follows whatever colour the surface gives the link. There are no --link-* component tokens; a surface re-colours links by setting color, as the stage, footer and band do.

/* How the stage re-colours every plain link inside it */
:is(.on-stage, .topbar) a:not(.btn) { color: inherit; }
:is(.on-stage, .topbar) a:not(.btn):hover { background: none; color: var(--color-accent-on-stage); }

On newsprint the link is charcoal ink, the same as body text, and the underline carries the meaning. In dark mode it is paper (--palette-ink-100) and hovers to yellow. On the stage in both themes it is paper and hovers to yellow with no fill, because a yellow fill under paper text would fail contrast.

Accessibility

Role and pattern

Native <a href>, following the APG Link pattern. Never put role="link" on a <span>, and never use href="#" with a click handler for an action: use a button.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the link in DOM order.
EnterFollows the link.
SpaceScrolls the page. It does not follow a link, which is one reason actions must be buttons.

Focus

The shared ring: a 3px outline with a 3px offset, ink on newsprint and yellow on the stage and in dark mode. It follows the link’s inline box, so a link that wraps onto two lines shows a ring on each line.

Labelling

The link text is the accessible name and must make sense on its own (WCAG 2.4.4): “See all 38 reviews”, not “See more”. Icons are aria-hidden. External links add a visually hidden “(opens in a new tab)”. When several links on a page share a label, such as “Profile” in a list of tickets, make the text unique (“Elijah Park’s profile”) instead of reaching for aria-label.

Contrast

Link text matches body text, so colour alone does not mark a link. The underline does (WCAG 1.4.1).

Motion

The highlight and the arrow nudge take --duration-fast (90ms). Under prefers-reduced-motion they change instantly. Smooth scrolling to in-page anchors is switched off too.

Touch

Links inside a sentence are exempt from the 24px target rule (WCAG 2.5.8 inline exception). Standalone links have a 24px minimum height and sit at least 8px from other targets. Nothing depends on hover: the highlight is a bonus.

Content

  • Name the destination: “How booking works”, “Abigail’s reviews”, “hello@zamaro.ca”. Never “click here”, “read more” or a bare URL.
  • Link the few words that say where it goes, not a whole sentence.
  • Sentence case in the source. Standalone links are uppercased by CSS.
  • External links name the site: “Watch on YouTube”, not “Watch here”.
  • Keep standalone links to four words or fewer so the arrow stays on the line at 360px.
