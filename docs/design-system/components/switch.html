Switch

A switch turns a setting on or off right away, with no Save button: “Email me when an artist accepts”. On is a yellow track with the ink thumb at the right.

WCAG 2.2 AAStatus: stablerole="switch"Class .switch

Overview

Use a switch for a preference that takes effect as soon as it changes and stays that way: Naomi’s notification settings, “Show prices with the Zamaro fee included”. The change is saved at once and confirmed with a short status message.

  • An answer that is sent with a form (“Bring backing tracks”): checkbox.
  • Turning a filter on the lineup on or off: a filter chip.
  • An action that happens once (“Send reminder”): a button.

The control is an <input type="checkbox" role="switch">, visually hidden and followed by a drawn .switch__track whose thumb is a pseudo-element.

Anatomy

  1. Track48 × 24px pill, 2px rule. Off: subtle grey fill, charcoal rule. On: yellow fill, ink rule.
  2. Thumb16px circle. Off at the left in body ink; on at the right in ink on yellow. Moves on the spring easing.
  3. LabelNames the setting, not the action. The accessible name; the whole row is clickable.
  4. Description (optional)Body small, muted: what on means in practice.

Variants

Label right (default)

The track leads, like a checkbox. Use this in forms and in single settings.
HTML
<label class="switch">
  <input type="checkbox" role="switch" name="notify-accept" checked>
  <span class="switch__track"></span>
  <span class="switch__text">Email me when an artist accepts</span>
</label>

Label left, in a settings list

Notifications

Changes save as soon as you flip a switch.

.switch--start puts the label first and the track at the end of the row, so a list of settings lines up on the right. Flip one: the status line confirms the save.

Sizes

Switches have one size: a 48 × 24px track in a row at least 24px tall.

States

Hover and focus are forced with data-state on the label; the forced focus rows set outline: none inline so only the track shows the ring, as in the product.

ValueDefaultHoverFocusDisabled
Off
On

A switch has no invalid state: any value is valid. If saving fails, flip it back and say so in a danger toast: “Couldn’t save your email setting. Try again.” There is no busy style either; saving is fast, and the switch stays usable.

Both themes

  • Hover darkens the track’s rule to body ink.
  • On fills the track yellow and slides the thumb right. Position, not colour, is the main cue.
  • Disabled greys the track and the label. Use it only when the setting can’t apply yet, and say why in the description (“Add a phone number to get texts”).

Responsive behaviour

  • The track never shrinks. The label wraps beside it.
  • In settings lists (.switch--start) the track stays at the end of the row at every width, so a column of switches is easy to scan on a phone.
  • Keep switches out of narrow table cells and toolbars; they need their label.

Theming

The track has three component tokens: --switch-bg (--color-bg-subtle), --switch-border (--color-border-strong) and --switch-thumb (--color-fg-default). On sets them to --color-accent, --color-border-on-accent and --color-fg-on-accent; hover sets the border to --color-fg-default. Disabled is meant to grey the track, but today the rule sets the checkbox’s --control-* tokens, which the track does not read, so only the label greys. The disabled examples on this page set --switch-bg, --switch-border and --switch-thumb inline to show the intended look.

In dark mode the off track is a charcoal pill with a light rule and a paper thumb; on is the same yellow with an ink thumb as on paper.

Accessibility

Role and pattern

A native checkbox with role="switch", following the APG Switch pattern. Screen readers announce “switch, on” or “off”. Groups of switches go in a <fieldset> with a <legend>.

Keyboard

KeyAction
Tab / Shift+TabMoves to and from each switch.
SpaceFlips it. The change is saved at once.
EnterDoes nothing on a native checkbox switch (it would submit a form, so keep switches out of forms).

Focus

The ring goes around the track (input:focus-visible + .switch__track): 3px, 3px offset, ink on paper, yellow in dark mode. It follows the pill shape.

Labelling

The label names the setting in a way that reads true when on: “Email me when an artist accepts”. Never change the label with the state (“Turn on emails” / “Turn off emails”); the role already says on or off. The result of a change is announced through a polite role="status" message (“Saved. We’ll email you when an artist accepts.”).

Contrast

Off track rule on card
Off thumb on track
On thumb on yellow
On track rule on card
Description
Dark: off track rule on card
Dark: off thumb on track
Dark: on track fill on card

On paper the ink rule separates the yellow track from the card; on the stage the yellow fill itself does. The thumb position carries the state without colour.

Motion

The thumb slides over --duration-base (160ms) on --ease-spring, a small overshoot like a flicked toggle. Under reduced motion it jumps.

Touch

The track is 48 × 24px; the label row is the real target. Rows in a settings list are 12px apart.

Content

  • Label the setting, in sentence case, as a statement that is true when on: “Email me when an artist accepts”, “Show prices with fees included”.
  • No “Enable”, “Turn on” or a question mark.
  • Use the description for the practical detail: where, when or how often.
  • Confirm the save in a few words: “Saved. We’ll text you the day before each event.”
