Component · Inputs

Checkbox

A checkbox says yes to something on its own line: what Naomi needs from an artist, that she has read the cancellation terms. Several can be ticked at once, and a ticked box fills butter yellow.

WCAG 2.2 AAStatus: stableNative <input type="checkbox">Class .check

Overview

Use a checkbox for an independent yes/no that takes effect when the form is sent, or for picking any number of options from a short list. In the booking request: “What would you like from the artist?” and “I’ve read the cancellation terms”.

  • One choice from several: radio group.
  • A setting that applies at once, with no submit: switch.
  • Filters that apply instantly to the lineup: filter chips.

The box is a real <input type="checkbox">, visually hidden but focusable, followed by a drawn .check__box that holds two icons: a tick for checked and a dash for indeterminate.

Anatomy

  1. Box24px square (--target-min), 2px charcoal rule, surface fill. Square corners like everything else.
  2. MarkTwo icons in the box: .check__tick (checked) and .check__dash (indeterminate), 16px, 3px stroke, ink on yellow. They share one grid cell; the examples here set grid-area: 1 / 1 inline until components.css does.
  3. LabelBody text, the accessible name. The whole row is clickable because it is a <label>.
  4. Description (optional)Body small, muted, under the label. Part of the name, so keep it to one sentence.

const all = document.querySelector('[data-check-all]');

all.indeterminate = on > 0 && on < items.length;

Sizes

Checkboxes have one size: a 24px box in a row at least 24px tall, with the label as part of the target.

States

Hover and focus are forced with data-state on the .check label. Indeterminate boxes on this page are set by script.

Both themes

Responsive behaviour

  • Groups stack vertically at every width; 12px (--space-3) between options. Labels wrap under themselves, never under the box.
  • .choice-group--inline lays short options in a row that wraps. Use it only for two to four one-word options.
  • Long lists (more than eight) belong behind a “Show all styles” button, not a scrolling box.

Theming

The box has three component tokens shared with the radio dot: --control-bg (--color-bg-surface), --control-border (--color-border-strong) and --control-fg (--color-fg-on-accent, the mark). Checked and indeterminate set --control-bg to --color-accent and the border to --color-border-on-accent; hover sets the fill to --color-accent-subtle; disabled uses --color-bg-subtle and --color-fg-disabled; invalid sets the border to --color-danger-border.

In dark mode the empty box is charcoal with a light rule, and the checked box keeps its yellow and ink tick, the same as on paper.

Accessibility

Role and pattern

Native <input type="checkbox"> inside a <label>, which gives the APG Checkbox pattern for free, including the mixed state through the indeterminate property. Groups are a <fieldset> with a <legend>.

Keyboard

KeyAction
Tab / Shift+TabMoves to each checkbox in turn; every box is a tab stop.
SpaceToggles it. An indeterminate “All” becomes checked and ticks every child.
EnterSubmits the form; it does not toggle.

Focus

The input is hidden, so the ring is drawn on the box (input:focus-visible + .check__box): 3px with a 3px offset, ink on paper, yellow in dark mode. The forced focus examples on this page set outline: none on the label, because the generic [data-state="focus"] rule would also ring the whole row.

Labelling

The wrapping label names the box; the description inside it is part of the name, so keep it short. The legend names the group. A parent “All styles” box lists the boxes it controls in aria-controls. Screen readers announce indeterminate as “mixed” or “half checked”. An error is linked from the input with aria-describedby.

Motion

The fill changes over --duration-fast; nothing moves. Instant under reduced motion.

Touch

The box is 24px, the WCAG minimum; the label makes the real target the whole row, usually 300px or more wide. Rows are 12px apart.

Content

  • Write the label as the thing that will be true when ticked: “Bring backing tracks”, “I’ve read the cancellation terms”. No “Check to…”.
  • Sentence case, no full stop. Descriptions are one sentence with a full stop.
  • The legend is a question or a noun phrase: “What would you like from Abigail?”, “Styles”.
  • Never pre-tick consent or anything that costs money.
  • The parent of an indeterminate group is “All {things}”: “All styles”.
