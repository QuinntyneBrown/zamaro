Zamaro design system

The visual language for booking praise and worship artists around Toronto, written down once. Charcoal ink on newsprint, one butter-yellow fill, condensed poster type, square corners and hard print shadows. Every decision is a token; every component documents every state in both themes.

How to use

  1. Link the two stylesheets, tokens first: 
    <link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="assets/components.css">
  2. Use the classes and attributes shown on each component page’s Code section (.btn btn--primary, .ticket, aria-pressed…). State comes from real attributes; data-state is for documentation and mocks only.
  3. Never write a raw colour, size or duration: read a semantic token (var(--color-fg-muted), var(--space-6)). To re-skin a component, override its component tokens (--btn-bg).
  4. Themes: nothing for light; data-theme="dark" on <html> forces the stage, and the OS preference applies otherwise. data-theme="light" makes a paper island.
  5. Other platforms: generate constants from tokens/tokens.json (W3C DTCG).
  6. Before shipping a change, run the two checkers listed in the README.

Keyboard: press t on any page to switch theme, or add ?theme=dark to the URL.
