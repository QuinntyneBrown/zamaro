Spacing

A 4px scale. Tight inside the ticket, generous between sections: the poster breathes and the small print stays tight.

Overview

Every padding, gap and margin comes from --space-*. The number is the multiple of 4px (--space-5 is 20px). Spacing never scales with the viewport. A breakpoint swaps the token instead (see Layout).

Inside and between

RelationshipTokenExample in the mocks
Icon to label--space-2Heart and “Saved” in a button
Label to control--space-1“Event date” over its input
Between fields--space-4 to --space-5Booking bar (16px), stub (20px)
Inside a ticket body / alert / card--space-5 to --space-6Ticket body 20px, alert 24px
Inside a hero card--space-8 to --space-10Headliner 32px → 40px at lg
Between tickets--space-8The lineup grid
Section head to content--space-8“The lineup” to the filters
Between sections--space-16 → --space-20Lineup, how booking works, band

Rule of thumb: inside a component use --space-6 or less; between components use --space-6 or more. Related items sit closer than unrelated ones.

Control heights and padding

SizeHeightSide paddingLabelUsed for
sm--control-height-sm 36px--space-3--font-size-xsRow actions (“Pick”)

Usage

  • Use gap on .stack and .cluster rather than margins on children.
  • Off-grid values from the mocks were snapped: a 30.4px brand mark became 32px; 0.9rem skeleton bars became 16px; a 14.4px ticket notch became 16px; shadow offsets of 3px and 5px became 4px and 6px.
  • --space-0-5 (2px) is only for badge padding and hairline nudges.
