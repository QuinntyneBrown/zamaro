Foundation

Color

Charcoal ink on warm newsprint, one butter-yellow fill, and a charcoal stage that stays dark in both themes. Every pairing is checked to WCAG 2.2 AA.

Overview

Zamaro is printed, not lit. The light theme is newsprint: warm off-white paper and a charcoal ink that is softer than black (11:1 instead of 21:1), so long profiles read calmly. The dark theme is the stage: deep charcoal with paper-coloured text and yellow hard shadows, like a band lit from the front.

  • One accent. Butter yellow (--color-accent) marks the primary action, what’s free, current and selected. Nothing else is yellow.
  • Yellow is a fill. On newsprint it is only ever a background with ink on it (8:1). It is never a text colour on paper (1.4:1). On the stage and in dark mode it can be text (10:1).
  • The stage is always charcoal. The top bar, poster hero and footer use stage tokens in both themes, so the page always opens like a gig poster.
  • Paper islands. The booking bar stays paper even on the dark stage, using data-theme="light" (see Theming).

Primitive ramps

Primitives are raw colours. Only the semantic tokens read them, and changing a ramp re-colours the whole product. The ink ramp is warm (a hint of brown), so charcoal never looks blue next to newsprint.

Status colours

Status colours always travel with an icon and words (WCAG 1.4.1). Info is ink on warm newsprint rather than blue, so the yellow accent stays the only hue that means “look here”. Danger is the only red; success is a press-green used for confirmations; warning is amber.

Usage

  • Use the role that describes the job (--color-fg-muted for secondary text), never the colour you want (--palette-ink-600).
  • Muted text (6:1) is for metadata and help. Subtle text (at least 4.9:1) is for placeholders and small print only. Disabled text is exempt from contrast and must never carry information.
  • Rules: --color-border-strong (9:1) outlines controls, cards and tickets. --color-border-default is a decorative hairline for list dividers only and never the only edge of a control.
  • Yellow fills on paper always get an ink outline (--color-border-on-accent): the fill alone is 1.4:1 against paper and would vanish for some readers.
  • On the stage, use --color-fg-on-stage, --color-fg-on-stage-muted and --color-accent-on-stage. Never use the page roles there; they flip with the theme and the stage does not.
  • Halftone artwork uses its own pair so placeholders read as texture, not noise, in both themes.

Accessibility

  • Both themes meet WCAG 2.2 AA for every declared pair (1.4.3 text, 1.4.11 non-text, 2.4.11 focus). The tightest real pair is subtle text on a raised dark surface at 5.2:1.
  • Colour is never the only signal: “Booked” is muted and struck through, “Free” is yellow and labelled, errors have an icon and a sentence.
  • prefers-contrast: more raises hairlines to strong rules and muted and subtle text to the default ink. forced-colors: active hands focus and rules to system colours.
  • The ink is deliberately not black. Pure black on white (21:1) causes halation for some dyslexic and low-vision readers; 11:1 is comfortably above AAA (7:1) for body text.

Adding a brand theme

A partner theme, such as a denomination’s co-branded event page, overrides semantic roles only, in a new block in tokens.css. Then run the contrast check for the new theme.

[data-theme="harvest"] {
  --color-accent: var(--palette-amber-300);
  --color-accent-hover: var(--palette-amber-50);
  --color-fg-on-accent: var(--palette-ink-750);
  --color-accent-on-stage: var(--palette-amber-300);
  --color-shadow: var(--palette-ink-700);
}
/* then: python check_contrast.py tokens/tokens.css --theme harvest */
