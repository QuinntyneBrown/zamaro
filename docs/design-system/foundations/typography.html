Foundation

Typography

Three voices: a condensed poster face for names, dates and prices, a quiet sans for reading, and a stamped mono for the small print on the ticket.

Body 16pxMin 12pxDisplay uppercase via CSS

Overview

Type does most of the gig-poster work. A booker should find the artist’s name, the date and the price from across the room, then read the bio comfortably up close.

Families

Display · --font-family-display

Lead worship? Get on the bill.

Sans · --font-family-sans

She had the whole congregation singing in three-part harmony by the last verse.

Mono · --font-family-mono

No. ZAM-0114 · Admit one church

The product self-hosts Bebas Neue. The rest of the stack (Anton, Oswald, Impact, Arial Narrow) keeps mocks and docs condensed offline; with no condensed font installed it falls back to a plain sans.
  • Display is a condensed grotesque, always uppercase, regular weight (the face is heavy already). It is for headlines, names, dates and prices: things you would see across a room on a poster.
  • Sans (Helvetica Neue) carries reading: bios, reviews, help, buttons.
  • Mono is the ticket small print: numbers, codes, field labels, facts. It looks stamped and keeps numbers aligned.

Scale and roles

Use the role shorthands (font: var(--text-h3)), not sizes. Each role bundles weight, size, line height and family.

Weights, line height and tracking

Regular 400 Medium 500 (mono) Bold 700 Black 900

Body is regular; labels and buttons are bold; mono is medium. Black is reserved for a heavy wordmark if a black cut is self-hosted later, and nothing uses it today. Line heights run from poster (0.86, stacked display lines touch) to relaxed (1.75, quotes and leads). Tracking is slightly negative on display, wide (0.08em) on uppercase sans labels and stamp (0.18em) on mono overlines.

Usage

  • Prose is capped at --layout-measure (58ch). components.css sets it on every <p>.
  • Headings use text-wrap: balance; paragraphs text-wrap: pretty.
  • Display names break anywhere (overflow-wrap: anywhere), so “Grace Tabernacle Mass Choir” never pushes the page sideways at 360px.
  • Display sizes h1, display and poster are fluid with clamp() (for example h1 is 48px at 360px and 88px at 1280px). Everything at body size and below is fixed, so browser zoom and user font size always win.
  • Never set display type in lowercase or sentence case; never set reading text in the display face.

Accessibility

  • Nothing is smaller than 12px (--font-size-xs); body is 16px; all sizes are in rem.
  • Uppercase is applied with CSS (text-transform), never typed, so screen readers read words, not letters, and copy stays in sentence case in the source.
  • Line height 1.6 and the measure satisfy 1.4.8 guidance; layouts survive the 1.4.12 text-spacing override (1.5 line height, 0.12em letter spacing) because no text box has a fixed height.
  • Display type is large text (at least 24px), but all colour pairs still meet the 4.5:1 body-text minimum.
