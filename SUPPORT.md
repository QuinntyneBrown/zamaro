# Support

## How to get help

Zamaro is in the design phase and is maintained on a best-effort basis.

| You want to | Do this |
|---|---|
| Ask a question about the project, requirements or designs | Search [existing issues](https://github.com/QuinntyneBrown/zamaro/issues), then open an issue with the **Question** label |
| Report a bug | Open an issue with the **Bug report** template |
| Propose a feature or a behaviour change | Open an issue with the **Feature request** template |
| Report a security vulnerability | Follow [SECURITY.md](SECURITY.md). Do not open a public issue |
| Report a code of conduct concern | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before you ask, check the [README](README.md), the [contributing guide](CONTRIBUTING.md)
and the documentation in [`docs/`](docs/).

## Response times

Maintainers aim to triage new issues within one week. There is no service-level
agreement.

## Commercial support

There is no commercial support for Zamaro.
